## 💡 О проекте

**Один мод для перевода всех остальных.** Цель — в один клик получить полноценный атмосферный геймплей с сотнями модификаций на вашем языке. Никаких разрозненных паков, поиска совместимости или потери контента из-за языкового барьера. Задумка глобальная — переводы на все популярные языки. На текущий момент я фокусируюсь на двустороннем RU ⟷ EN переводе: русские моды на английский, английские на русский. После отладки, тестирования и получения обратной связи от сообщества — расширение на остальные языки.

## ⚙️ Установка и использование

Переместите модификацию Project Translate в mods и поставьте её в конец очереди загрузки — так переводы будут применяться поверх всех остальных модов.

## 🤝 Как помочь проекту

На текущий момент я разработал для себя инструменты, которые упрощают процесс создания переводов. **Не нужно отправлять pull requests с обновлениями в файлы переводов** — они генерируются автоматически, и вы только зря потратите время.

Если модификация наберёт популярность и я не смогу своевременно поддерживать её актуальность в одиночку, я постараюсь сделать инструменты для поддержки сообщества. Но пока отвлекаться на это не буду.
